# 데이터 촬영 가이드 — 앉은 상반신 기준 (직접 학습용)

> 2026-11-24 v2 · `ACTION_GUIDE.md`의 카메라 세팅(책상 위 근거리, 앉은 상반신)을 **학습 데이터에도 그대로** 적용한다.
> 학습 영상과 서비스(IP Webcam) 화면 조건이 같아야 모델이 잘 맞는다.
> 핵심 3가지: ① 머리 위 한 뼘 ~ 골반까지 화면 안 ② 카메라 고정 ③ 한 파일 = 동작 1회

---

## 1. 모델 입력 규격

| 항목 | 값 | 촬영에 주는 의미 |
|---|---|---|
| Pose | YOLO11 Pose, COCO 17 관절 | 무릎·발목은 안 보여도 됨 |
| Step당 Feature | 38 = 관절 좌표 34(17×x,y) + 관절 각도 4(양 팔꿈치·양 어깨) | 팔·어깨가 가려지면 안 됨 |
| 정규화 | **어깨 중심·어깨 너비 기준** | 골반이 살짝 잘려도 입력 전체가 흔들리지 않음 |
| Sequence | **30 Step = 5초** (30fps 영상에서 5프레임마다 1개, 6fps) | 동작 1회를 **4~5초 안에** 수행 |
| 모델 입력 | 30 × 38 = **1,140 Feature**, **4 Class** (A003·A004·A005·A006) | Feature 규격은 교과와 동일. A001·A002는 앉은 화면에서 안 보여 제외 |

IP Webcam 8초 수집 → 5초 창을 밀어 가며 여러 번 추론 → 사람별 대표 결과 1건.

## 2. 카메라 세팅 (모든 영상 공통, ACTION_GUIDE §1과 동일)

| 항목 | 기준 |
|---|---|
| 기기 | 나중에 IP Webcam으로 쓸 **같은 휴대폰** |
| 위치 | 책상 위 정면, 모니터 위 또는 모니터 아래 (아래 '각도 2가지') |
| 거리 | 몸에서 0.8~1.2m |
| 방향·화질 | 가로, 720p 이상, **30fps** |
| 화면 안 | 머리 위 **손 한 뼘 여유** ~ **골반**, 양 어깨·팔꿈치·손목 |
| 조명 | 얼굴 쪽에서 오는 빛, 뒤에 창문 X |
| 확인 | 앉은 채로 두 팔을 머리 위로 뻗어 손끝이 화면 안에 있는지 |

**각도 2가지** (파일명의 `top` / `bottom`):
- `top`: 모니터 위. 눈높이보다 조금 위에서 살짝 내려다봄
- `bottom`: 모니터 아래(책상 위 거치대). 살짝 올려다봄. 책상 모서리에 골반이 가려지는 건 정상 (Feature는 어깨 기준이라 영향 적음, 검사에서도 골반은 확인 안 함)
- 두 각도 모두 정면에서 찍고, 서비스에서 실제로 쓸 위치를 반드시 포함한다.

## 3. 동작별 수행 방법

모든 클립: **[정지 1초] → [동작 1회, 4~5초] → [정지 1초]**, 전체 **6~8초**.

| ID | 라벨 | 서비스 역할 | 수행 (앉은 채로 시작) | 주의 |
|---|---|---|---|---|
| A004 | `drink_return` | **미션 · 물 마시기** | 컵을 책상에서 들어 → 1~2초 마시기 → 내려놓기 | 컵이 얼굴 전체를 가리지 않게. 왼손·오른손 섞기 |
| A006 | `wave` | **미션 · 어깨 풀기** | 한 팔을 머리 위로 들어 좌우 3번 이상 흔들고 내리기 | 손끝이 화면 위로 안 나가게. 왼팔·오른팔 섞기 |
| A005 | `sit_stand` | **습관 · 일어나 움직이기** | 일어섰다가 다시 앉기 | 머리가 화면 밖으로 나가는 게 **정상** |
| A003 | `walk_turn_walk` | **습관 · 일어나 움직이기** | 일어나 2~3걸음 걸어 화면 밖으로 → 돌아와 앉기 | 5초 안에 돌아오기 어려우면 "일어나 옆으로 한 걸음 → 돌아와 앉기"로 통일 |

> **A001 허리 숙이기·A002 다리 들기는 촬영·학습하지 않는다.** 근거리 앉은 화면에서 허리·다리가 보이지 않기 때문 (README 한계·설계 근거로 기록, 강사 확인 필요: 과제 원안은 6 Class).
> A005·A003은 앉은 상반신 화면에서 서로 비슷해 보이므로 서비스에서는 **하나의 습관으로 묶는다**. 판정 점수 = 두 클래스 확률의 합.
> 서비스 습관 3개: 물 마시기(A004) · 어깨 풀기(A006) · 일어나 움직이기(A003+A005).

## 4. 몇 개 찍어야 하나

| 조건 | 권장 (3명) | 최소 (2명) |
|---|---|---|
| 사람 | P01~P03 | P01~P02 |
| 각도 | top + bottom | top + bottom |
| 반복 | 사람·각도마다 5회 | 사람·각도마다 5회 |
| 총 학습 클립 | 4 × 3 × 2 × 5 = **120개** | 4 × 2 × 2 × 5 = **80개** |

> 바뀌는 조건은 **사람과 카메라 각도뿐**이다 (날짜·장소·옷 구분 없음). 그래서 학습/평가는 사람 단위로 나눈다 (6장).

예상 소요: 클립당 약 12초 → 80개 기준 **촬영 약 20~25분**.

### 4-1. NG 영상 (`other` 클래스로 학습 + 기준값 결정) — 미션 자동 인식에서 가장 중요

> X### 폴더 영상은 모두 `other`(기타 동작) 클래스로 학습한다. 모델이 습관이 아닌 행동을 '기타'로 답할 수 있어 잘못 인정이 줄어든다.
> 교차검증에서는 NG 행동 하나를 통째로 빼고 학습해 '처음 보는 행동'이 걸러지는지 본다 (`training/train_rf.py`).
> 지금은 P01·top만 있으므로 **다른 사람·bottom 각도의 NG 영상을 추가할수록 효과가 커진다.**

미션을 선택하지 않으면 "고른 미션과 다르면 NG"라는 안전장치가 사라진다.
**모델이 기록 대상 동작이라고 착각할 만한 행동**을 일부러 찍어 기준값을 정한다.
각 8초, 동작은 8초 중 아무 때나 자연스럽게, **행동마다 3개** (top 2 + bottom 1).

| 폴더 | 행동 | 헷갈릴 동작 |
|---|---|---|
| `X001_sit_still` | 가만히 앉아 화면 보기 | (기본 NG) |
| `X002_typing` | 타이핑·필기·책 넘기기 | (기본 NG) |
| `X003_phone` | 휴대폰 보기 | (기본 NG) |
| `X004_scratch_head` | 머리 긁기·턱 괴기 | A004 물 마시기 |
| `X005_touch_face` | 안경 고쳐 쓰기·하품 가리기 | A004 물 마시기 |
| `X006_phone_call` | 휴대폰을 귀에 대고 통화 | A004 물 마시기 |
| `X007_stretch_up` | 두 팔 기지개 | A006 어깨 풀기 |
| `X008_hand_raise` | 손 들기(질문하듯) | A006 어깨 풀기 |
| `X009_touch_hair` | 머리 쓸어 넘기기·묶기 | A006 어깨 풀기 |
| `X010_shift_seat` | 의자에서 엉덩이 들썩·자세 고쳐 앉기 | 일어나 움직이기 |

→ 10개 × 3 = **30개, 약 10분**. (허리 숙이기는 기록하지 않으므로 그와 헷갈리는 NG는 생략) 파일명 규칙은 학습 영상과 같다 (`P01_top_R01.mp4`).

### 4-2. 시나리오 테스트 영상 (`data/test/`, 학습 제외)

| 폴더 | 내용 | 개수 | 목적 |
|---|---|---|---|
| `test/natural/` | 습관 동작 3개(물·어깨·일어나기)를 8초 중 **앞·중간·끝** 다른 시점에 수행 | 3 × 3 = 9 | 동작 위치가 달라도 잡히는지 |
| `test/combo/` | 8초 안에 물 마시고 → 손 흔들기 | 3 | 한 작업에 동작 2개일 때 규칙 확인 |

### 4-4. 미션 자동 인식 판정 규칙 (참고)

| 순서 | 조건 | 결과 |
|---|---|---|
| 1 | FAILURE 또는 사람 없음 | NG · 분석 실패 / 사람 없음 |
| 2 | 습관별 점수 계산: 물 = p(A004), 어깨 = p(A006), 움직이기 = p(A003)+p(A005) | — |
| 3 | 가장 높은 습관 점수 < 그 습관의 기준값 | NG · 판단 불확실 |
| 4 | 그 외 | **OK · 해당 습관 자동 기록** |

- 미션을 **선택한 경우**는 기존 규칙(선택과 일치해야 OK)을 그대로 쓴다.
- 기준값은 **동작별로** 정한다. NG 영상 중 A004로 잘못 나온 최고 점수보다 A004 기준값을 높게 잡는 방식.
- 한 작업에서는 대표 라벨 1개만 기록한다 (`combo` 영상으로 동작 확인).

```text
│   ├── P01_bottom_R01.mp4

├── A006_wave/

```

`P01_top_R03.mp4` = 사람(Person) 01, 모니터 위 카메라(top), 3번째 반복(Repeat)
- 실명 대신 P번호. 실명 대응표는 Git에 올리지 않음
- 각도: `top` = 모니터 위, `bottom` = 모니터 아래
- 반복 번호는 사람·각도·동작마다 R01부터 다시 시작

## 6. 학습/평가 분리

- 같은 사람의 클립이 학습과 평가에 동시에 들어가면 모델이 동작 대신 그 사람의 체형·옷을 외워 정확도가 부풀려진다.
- **사람 단위 교차검증**: 한 명씩 돌아가며 평가용으로 빼고 나머지로 학습 (3명 → 3번, 2명 → 2번). 평균 정확도를 README에 기록
- 서비스에 넣는 **최종 모델은 모든 사람의 영상으로** 다시 학습한다.
- 각도별 정확도(top / bottom)도 따로 기록해 어느 거치 위치가 더 잘 맞는지 확인한다.

## 9. 자주 하는 실수

| 실수 | 결과 | 예방 |
|---|---|---|
| 팔을 들면 손끝이 화면 위로 나감 | `wave` 손목 결측 | 머리 위 한 뼘 여유 |
